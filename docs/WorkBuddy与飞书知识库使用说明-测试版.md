# WorkBuddy 与飞书知识库使用说明（测试版）

更新日期：2026-10-20。本文仅描述独立测试组织中的虚构数据演示。

## 目前怎样使用

员工在 WorkBuddy 对话中通过 `feishu-datacenter-employee` 连接器提交本地 PDF、DOCX、XLSX、TXT 文件，或提交、修订和查询本人日报。连接器调用运行在当前电脑上的 MVP 服务；服务校验员工凭证和空间权限，再将文件写入飞书测试目录及文件台账，将日报写入飞书多维表格。WorkBuddy 返回归档 ID、状态和飞书链接，并可再次查询处理状态。

管理员在飞书工作台打开“飞书企业数据中心MVP测试”，查询有权查看的归档台账、上传文件、查看日报汇总及任务状态。管理员也可在测试多维表格中核对员工日报原始记录。当前电脑休眠或服务停止时，已写入飞书的数据仍在，但新的 MVP 提交和汇总不能运行。

## 飞书知识库现在的状态

测试组织已建立“飞书企业数据中心MVP测试知识库”，向该组织成员开放，只用于虚构数据的使用说明。当前归档文件仍位于飞书云盘的公共或财务测试目录，日报位于测试多维表格；文件不会自动进入知识库。知识库扩展复用同一 MVP 服务和员工连接器。

2026-10-20：本机测试服务已启用知识库功能，已有原生在线文档及 TXT 文件实际写入成功，并通过 stdio MCP 读回、去重与重启检查。现有四项员工工具加六项知识库工具，共10项。WorkBuddy 客户端需重连现有连接器以加载工具；客户端自然语言调用及 hyh 飞书打开仍需验证。

## 使用知识库

新增能力：将明确选定的对话整理为在线文档；将授权上传目录中的 PDF、DOCX、XLSX、TXT 原文件发布为知识库文件节点；列出配置首页的直接子节点、按标题筛选当前页；读取授权库内在线文档正文。附件只返回打开链接，不解析内容。不是全库全文搜索或独立 RAG 问答系统。

员工只需说“把刚才这段你好对话整理到测试知识库”或“把你好演示.txt放到测试知识库”。连接器负责选择工具，服务端负责权限和回执。当前只接入组织公开的虚构测试库，不能自动搬运财务归档或日报。知识库发布记录暂存在持久化 SQLite 并写审计，未接入管理页的文件归档列表。

接入前须由测试组织管理员为应用开通相应飞书 Wiki 权限，并把应用加入专用知识库的授权范围。WorkBuddy 登录身份不自动等于飞书资源权限；服务端继续按已绑定的员工身份和允许访问的知识库范围鉴权。普通员工不得通过知识库接口读取财务资料。

## 演示判断

- 文件提交成功：WorkBuddy 返回归档成功，重新查询显示 `success`，飞书台账存在相同归档记录。
- 日报提交成功：WorkBuddy 查询本人日报，能读回日期、内容及飞书记录 ID；管理员可在飞书测试多维表中核对。
- 知识库接入成功：WorkBuddy 返回 `success` 和 Wiki 链接，重新读取内容一致，hyh 在飞书中实际打开可见；拒绝越权并留审计。目前**真实接口和 MCP 协议通过，WorkBuddy 界面与 hyh 飞书打开待验**。`pending` 和 `uncertain` 不能记为成功，不能改标题重复发送。

所有测试都使用虚构数据。当前电脑与临时 HTTPS 地址只用于演示；团队长期使用需要稳定运行的服务地址。
