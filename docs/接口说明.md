# 接口说明（D4 草稿）

基址：`http://localhost:3000`（可用 `PORT` 覆盖）  
统一错误体：

```json
{
  "ok": false,
  "error": {
    "code": "FORBIDDEN_SPACE | VALIDATION | NOT_FOUND | UPSTREAM | CONFLICT",
    "message": "人类可读说明",
    "request_id": "..."
  }
}
```

请求可带 `x-request-id` / `x-operator`。

---

## GET `/health`

健康检查与当前客户端模式、定时状态。

**200**

```json
{
  "ok": true,
  "mode": "mock",
  "time": "ISO8601",
  "daily_cron": { "enabled": false, "timezone": "Asia/Shanghai", "cron_expr": "0 20 * * *" }
}
```

## POST `/api/v1/archives`

multipart 归档文件。

| 字段 | 必填 | 说明 |
| --- | :---: | --- |
| `file` | ✓ | PDF / DOCX / XLSX / TXT，≤ 20MB |
| `department` | ✓ | 部门 |
| `confidentiality` | ✓ | `public` / `dept` / `mgmt` / `finance` |
| `space_id` | ✓ | 目标空间；财务空间需 elevated 操作者 |
| `operator` | ✓ | 操作者；也可用头 `x-operator` |
| `source` | | 默认 `api` |
| `file_type` | | 可省略，从扩展名推断 |
| `owner` | | 责任人，默认=operator |

**成功 / 去重 200**：含 `archive_id`、`file_id`、`feishu_url`、`content_hash`、`version`、`status`、`deduplicated`、台账关键字段。  
**无权限 403**（`FORBIDDEN_SPACE`，已记审计）  
**校验失败 400**

同空间同 SHA-256 → `deduplicated: true`，不新建飞书文件。  
同名同部门同空间、哈希不同 → `version` 递增，`previous_file_id` 指向旧版。

## GET `/api/v1/archives/:archiveId`

查询台账快照。

**200** `{ "ok": true, "archive": { ... } }`  
**404** 不存在

---

## POST `/api/v1/daily-summary/run`

手动（或模拟 cron）触发某日汇总；与 20:00 定时共用业务逻辑。

```json
{
  "business_date": "2026-10-14",
  "operator": "admin",
  "trigger": "manual"
}
```

**200**：`run_id`、`missing`、`summary_id`、`revision`、`message_sent`、`idempotent_skip_send`、`content_preview`。  
同日已推送则更新修订版且 **不再发送新消息**（`idempotent_skip_send: true`）。

---

## GET `/api/v1/daily-summary/schedule`

查看进程内定时状态（是否启用、时区、上次触发业务日）。真实系统 cron 可后置。
