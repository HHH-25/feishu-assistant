## 已处理问题

1. real 模式使用运行环境中的 Bearer 凭证映射身份，限制空间、财务权限和汇总权限；MCP 共用规则，拒绝操作记录审计。
2. 飞书 token 缓存、按空间选择目录、多维表读写、群消息和模型 Responses 请求已接入，敏感配置不写仓库。
3. SQLite 保存跨进程锁和发送/上传回执。发送或上传结果不确定时暂停自动重试，支持人工核对；上传已确认成功但台账失败时复用文件 token。
4. 发送结果不确定时不再发送失败通知，避免新增无法判断的消息。
5. 定时任务失败不记录当天已成功触发，允许可确认失败后的重试。
6. 联调前接口核对发现云盘目录上传误用素材接口，已改为 `/drive/v1/files/upload_all`；目录获应用可编辑权限后，四类文件真实上传均返回 file token。
7. 本地 `.env` 切换为真实飞书／模拟模型模式后，Mock 测试曾继承 `CLIENT_MODE=real` 而失败；Vitest 现在在导入业务模块前固定测试默认模式，8 个文件、32 个用例重新通过。
8. 应用发布并授予专用 Base 可编辑权限后，六张表由 91403 转为真实读取成功；2026-10-17 的 8 条虚构种子记录已写入，第二次写入保留原 record_id。
