## 已处理问题

1. real 模式使用运行环境中的 Bearer 凭证映射身份，限制空间、财务权限和汇总权限；MCP 共用规则，拒绝操作记录审计。
2. 飞书 token 缓存、按空间选择目录、多维表读写、群消息和模型 Responses 请求已接入，敏感配置不写仓库。
3. SQLite 保存跨进程锁和发送/上传回执。发送或上传结果不确定时暂停自动重试，支持人工核对；上传已确认成功但台账失败时复用文件 token。
4. 发送结果不确定时不再发送失败通知，避免新增无法判断的消息。
5. 定时任务失败不记录当天已成功触发，允许可确认失败后的重试。

## 尚待验证与风险

- 飞书多维表字段类型、应用权限、上传目录、文件链接模板、实际分页和错误码须在测试租户核验。当前适配器约定文本列并扫描表记录，适合 MVP 小数据量；大表需服务端过滤与索引策略。
- SQLite 必须是所有服务实例共享的持久状态；独立本地文件不能提供多实例幂等。备份与恢复时需要对账群消息及云盘文件。
- 飞书消息是否已送达、上传是否已成功但响应丢失，无法仅靠客户端状态推断，须人工按平台记录核对。
- Office 在线文档导入尚未接入，待基础 PDF/DOCX/XLSX/TXT 上传真实通过后开发与验收。
- T1–T10 当前均没有“真实通过”结论。
