# 部署说明（D3 草稿）

> 当前默认 `CLIENT_MODE=mock`，不依赖飞书/模型真实凭证。凭证就绪后再切 `real`。

## 1. 环境要求

- Node.js ≥ 18
- 操作系统：Windows / macOS / Linux 均可
- 网络：mock 模式无需外网；real 模式需访问飞书与模型 API

## 2. 安装与启动

```bash
cd feishuMVP
npm install
cp .env.example .env   # 按需填写；mock 可保持占位
npm start              # http://localhost:3000
```

开发热重载：`npm run dev`

## 3. 配置要点（环境变量）

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `CLIENT_MODE` | `mock` | `mock` / `real`（real 现为 stub） |
| `PORT` | `3000` | HTTP 端口 |
| `LOG_LEVEL` | `info` | 结构化 JSON 日志级别 |
| `FEISHU_*` / `MODEL_*` | 空占位 | **仅 real 需要**；勿把真实密钥提交入库 |
| `FEISHU_FINANCE_SPACE_ID` | `space_finance_test` | 业务层财务空间权限校验 |
| `DAILY_CRON_ENABLED` | `false` | `true` 时进程内每分钟检查，上海 20:00 触发 |
| `TZ` | `Asia/Shanghai` | 业务日与定时时区 |

密钥只放环境变量或密钥服务，禁止写入仓库、日志、前端与截图。

## 4. 验证

```bash
npm test          # 业务规则 + REST mock
npm run typecheck # TypeScript
curl http://localhost:3000/health
```

## 5. 演示两条 mock 闭环

## 6. 定时说明

- **推荐演示**：`POST /api/v1/daily-summary/run` 手动触发（与 cron 共用 `DailySummaryService`）。
- **可选进程内调度**：设 `DAILY_CRON_ENABLED=true` 后启动服务；到上海时区 20:00 触发一次/业务日。
- **生产级 cron**（系统 crontab / 云定时）可后置，届时回调同一手动接口即可。

## 7. 已知限制

- 真实 `FeishuClient` / `ModelClient` 为 stub，调用会明确报错。
- MCP Server 未挂载，仅有工具草案。
- Mock 台账/日报在内存中，进程重启后清空。
