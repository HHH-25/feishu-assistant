# 飞书工作台管理员入口演示

此演示只使用独立测试租户“用户601618的组织”和虚构数据。管理员页面由本项目的服务提供，飞书工作台负责打开页面和提供登录身份；云盘、台账与机器人仍由同一服务调用飞书接口。

入口在飞书客户端的**工作台 → 飞书企业数据中心MVP测试（网页应用）**，不是同名机器人的聊天窗口。机器人只负责向测试群推送摘要，目前不提供聊天指令。

管理页从本服务的 `/admin/feishu-h5-sdk.js` 加载飞书 H5 SDK；SDK 来源与本地兼容改动见 `src/vendor/README.md`。若手机页提示“请在飞书工作台中打开此应用”，先在飞书内刷新并检查该脚本是否加载，再核对飞书客户端登录能力，不能直接把该提示当作用户打开方式错误。

## 当前电脑临时演示

1. 本地忽略的 `.env` 保留飞书应用凭证、表格与目录配置，并设置 `CLIENT_MODE=real`、`ADMIN_WEB_ENABLED=true`、至少 32 字符的 `ADMIN_WEB_SESSION_SECRET`。首次获取管理员 `open_id` 时，可暂设 `ADMIN_WEB_ACTORS_JSON=[]`；此时任何账号都不能进入管理功能。
2. 另起演示服务，令 `PORT=3001`、`HOST=127.0.0.1`、`DAILY_CRON_ENABLED=false`。若已有 20:00 定时服务，保留其原进程；演示进程不负责定时任务。启动后仅本机可访问 `http://127.0.0.1:3001/health`。
3. 使用受信任的 HTTPS 隧道把本机 3001 端口临时暴露为一个 HTTPS 地址，或使用已有的 HTTPS 反向代理。例如从 Cloudflare 官方发布页取得 `cloudflared` 后运行 `cloudflared tunnel --no-autoupdate --url http://127.0.0.1:3001`，记录输出的 `https://...trycloudflare.com`。先确认该地址的 `/admin` 返回页面、`/admin/api/me` 在未登录时返回 401，再配置飞书。临时隧道地址随进程结束失效，**仅用于测试**；没有管理员登录态的页面不能读写业务数据，但任何拿到地址的人都能访问公开的健康接口。
4. 在飞书开发者后台打开现有测试应用，添加“网页应用”能力，将桌面端和移动端主页设为 `https://<演示地址>/admin`，并在“安全设置 → 重定向 URL”配置同一个完整地址。提交新版本，使用范围限定测试管理员。飞书官方说明发布后可从工作台搜索打开网页应用。
5. 管理员首次在飞书工作台打开时，页面会显示当前账号的 `open_id` 和“未获授权”。把该 ID **仅写入本地 `.env`** 的 `ADMIN_WEB_ACTORS_JSON`，例如 `[{"open_id":"ou_...","operator":"admin:test","spaces":["space_public_test","space_finance_test"],"can_run_summary":true,"finance":true}]`。重启演示服务后重新打开。不可按昵称或手机号猜测 ID，也不要把 API 密钥填入网页。
6. 验收：登录后查询文件台账，检查文件名、提交人、处理状态及“在飞书打开”链接；选择授权空间上传一份新的虚构 TXT；先用“仅查看运行状态”查看 2026-10-19 的任务、摘要正文和来源记录。“运行汇总（首次会推送）”会向测试群发送消息，只在确有测试应交名单或有效日报的日期使用，并确认重复运行没有第二条正常推送。

已完成的演示日期可直接**只读展示**：2026-10-19 是准点定时的真实飞书／模拟模型记录；2026-10-08 是当前电脑干净副本的真实飞书＋真实 DeepSeek 手动汇总，来源为员工 A/B、员工 C 缺交、财务日报已排除。选择日期后点“仅查看运行状态”，不要再点“运行汇总”制造修订版。归档列表中 `t10-clean-deploy-20261020.txt` 的最终飞书台账为 `success`；如果页面仍显示上传中途的 `pending`，点“查询”刷新。

每次演示前先核对临时 HTTPS 地址仍可访问；电脑休眠、服务或隧道关闭都会中断页面。面向长期使用时，迁到持续运行的主机和固定 HTTPS 域名，保留持久 SQLite 状态与飞书原生 ACL，再更新网页应用主页并重新验收。
